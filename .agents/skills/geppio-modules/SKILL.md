name: geppio-modules
description: Extract or review GeppIO workspace packages, runtime ports, capability lifecycles and standalone composition.
---

Trace the live owner and its callers before extracting a coherent capability. Declare public entries and package dependencies. Keep pure Runtime contracts free of DOM, React, Monaco, Electron and Node. Wire platform adapters at composition time.

Separate registration, selected activation, and disposal. Verify hiding a View preserves its model. Exercise a reduced composition and inspect which services start and stop. Keep installation and data identities distinct for generated apps.

For public libraries, pack their published shape locally and build a disposable external consumer using the declared entry points, assets and CSS. Report remaining coupling at a file or API boundary.
